# Secure Enterprise Network Lab

A secure enterprise network designed and implemented using Cisco Packet Tracer.

## Project Overview

This project demonstrates the design and configuration of a small enterprise network with a focus on network segmentation, access-layer security, and management connectivity.

## Technologies & Tools

- Cisco Packet Tracer
- Cisco IOS
- VLANs
- Port Security
- Sticky MAC Address
- Management VLAN
- IP Addressing
- Network Connectivity Testing

## Security Configuration

### Port Security
Port Security was configured on access switch ports to control which devices are allowed to connect to the network.

### Sticky MAC
Sticky MAC address learning was enabled to dynamically learn and secure connected devices' MAC addresses.

### Management VLAN
A dedicated Management VLAN was configured for switch management.

- VLAN: 60
- Management IP: 192.168.60.3/24
- Default Gateway: 192.168.60.1
